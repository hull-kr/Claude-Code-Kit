# Claude Code Kit (CCKit)

**Windows에서 [Claude Code](https://claude.ai/code)를 더 편하게 써주는 도구 모음**

트레이에 상주하는 컨트롤 패널로 Claude Code 세션을 열고·닫고·관리하고, 폰/웹에서 원격으로 조종할 수 있습니다. 이미지 붙여넣기, 백그라운드 전환, 리붓 자동 복원까지.

## 📥 설치

1. 위 **다운로드** 버튼으로 `CCKitSetup.exe` 받기 → 실행
2. **⚠️ "Windows의 PC를 보호했습니다" 경고가 뜹니다.**
   이 프로그램은 **무료 자유 소프트웨어라 코드 서명(유료 인증서)을 하지 않았습니다.**
   해로운 게 아니라, 서명이 없어서 Windows가 습관적으로 띄우는 경고예요.
   → **`추가 정보`** 클릭 → **`실행`** 누르면 설치됩니다.
3. 설치 후 트레이 아이콘(또는 바탕화면 아이콘) 더블클릭으로 패널을 엽니다.

> 💡 먼저 **Claude Code CLI** 가 설치돼 있어야 합니다 (`claude --version` 으로 확인).
> Windows Terminal 이 없으면 설치할 때 자동으로 깔아줍니다(winget).

## ✨ 기능

### 🖼️ 이미지 붙여넣기
캡처(`Win`+`Shift`+`S`) 후 터미널에서 **`Ctrl`+`Shift`+`V`** →
클립보드 이미지가 현재 폴더에 저장되고 그 경로가 자동으로 입력됩니다. (미리보기 팝업)

### 🗂️ 컨트롤 패널
- **탭:** ★관리 / ●열린 / ○닫힌 / ▦모든 세션 / ⚙설정 / ?사용법
- **상태 색:** 작업 중(주황) · 대기(초록) · 닫힘(회색) 으로 한눈에
- **서브에이전트 표시:** 세션이 Task/Agent 를 돌리면 상태칸에 `🔹N` 뱃지 → 클릭하면 작업 중인 서브에이전트 목록 팝업 (끝나면 자동으로 사라짐)
- **각 세션 버튼:** 관리(★)·리모트·열기·bg 전환·닫기/삭제
- **더블클릭:** 상태칸=상세정보, 제목칸=이름 바꾸기
- 여러 개 선택해 한꺼번에 열기/닫기

### ➕ 새 세션
하단 **`＋ 새 세션`** → 폴더 선택 + 세션명 + **원격 연결**(기본 켜짐) + 관리 추가(선택) → 만들기.
새 폴더의 "이 폴더를 신뢰?" 물음은 자동 통과, 이름도 자동 지정됩니다.

### 🌙 bg 전환
실행 중 세션을 백그라운드로 보냅니다. 터미널 탭은 닫히고 세션은 계속 실행 —
이름 앞에 `[MMddHHmm]` 시각이 붙습니다. '화면표시'로 언제든 다시 봅니다.

### 📱 리모트 컨트롤
세션의 **리모트**를 켜면 `/remote-control` 이 입력돼 **claude.ai/code 또는 모바일 Claude 앱**에서 이 PC의 세션을 조종할 수 있습니다.
이름 없는 세션은 리모트를 켜는 순간의 최신 대화가 제목이 됩니다(앱과 동일). 설정에서 절전 방지·유휴 유지도 지원.

### ★ 관리 세션 / 이어서 열기
자주 쓰는 세션을 **관리(★)** 에 담아두면 닫혀도 '관리 세션' 탭에 남습니다.
**`전체 이어서 열기`** 한 번이면 관리 세션들을 **열어뒀던 폴더에서 대화까지 이어서** 한꺼번에 다시 엽니다. (트레이 메뉴에서도 가능)

### 🔄 리붓 자동 복원
설정에서 켜두면, **리붓 직전 열려 있던 세션들을 로그인할 때 자동으로 다시** 엽니다.

### 🌐 다국어
한국어 / English / 日本語 / 中文

### ⌨️ ccd 단축 명령
```
ccd = claude --dangerously-skip-permissions
```
권한 확인을 건너뛰고 바로 실행 (설정에서 끌 수 있음)
